# ILIM Health Check

Šis projekts ir veidots Prakses II ietvaros. Ideja ir izstrādāt programmu, kas salīdzina TMS līgumu nosacījumus ar OVA un MARS izņēmumiem un palīdz atrast atšķirības datos.

Tiks izmantoti tikai sintētiski dati bez pieslēguma uzņēmuma sistēmām.

## Pašreizējais posms

Šobrīd ir izveidota projekta pamatstruktūra un vienkāršs palaišanas fails. Nākamajās izmaiņās tiks izveidotas pārējās funkcionalitātes.

Lai palaistu sākotnējo versiju, terminālī jāievada:

```powershell
py main.py
```
